# greedOS

Games and CSS from https://github.com/greedspilled/arctic-static; the rest is mine, about 33% vibecoded cuz of CSS and pushes. Enjoy.

The navigation labels are gS5 (Games), Grave (Browser), and GREEDGPT (AI).

Grave's ad and adult-content filters are off by default. Sites that fail through
the relay can be opened directly in a new tab.
Brave, Google, and DuckDuckGo searches request SafeSearch off.
