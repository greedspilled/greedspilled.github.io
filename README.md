## Greedified

Greedified plays audio files selected from your device and direct HTTP(S) audio links. It includes a searchable playlist, playback controls, shuffle, repeat, seeking, volume, and downloads. Remote downloads require the audio host to allow cross-origin requests. Only use audio you have permission to play or download.

The navigation labels are gs5 (Games), Greedle (Browser), Griscord (Chat), and GREEDGPT (AI).
